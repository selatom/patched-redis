============================================================
APPROACH
============================================================

The lancet coordinator has a "step" mode that sweeps RPS automatically
and keeps the agent connection alive the whole time (no warmup variance).

We run the coordinator with: -loadPattern "step:1000:80000:2500"
This sweeps from 1000 to 80000 RPS in steps of 2500.

For snapshots: a separate background process watches the coordinator
output (which prints "Load rate is X" for each step) and triggers
SIGUSR1 on the agent + redis-cli QUEUESTATE at the right times.

STEP 7: VM2 — CREATE SNAPSHOT SCRIPT
============================================================

cat > ~/snapshot_loop.sh << 'SCRIPTEOF'
#!/bin/bash
#
# snapshot_loop.sh — runs alongside the coordinator
# Waits for agent to start, then periodically takes snapshots.
#
# Usage: ./snapshot_loop.sh <agent_pid> <interval_between_snapshots>
#

AGENT_PID=$1
INTERVAL=${2:-2}
CLI="$HOME/patched-redis/src/redis-cli"
REDIS_HOST="10.0.0.1"
REDIS_PORT=6379
RESULTS="$HOME/results"
mkdir -p "$RESULTS"

SNAP_IDX=0

while kill -0 $AGENT_PID 2>/dev/null; do
  # Wait for snapshot pair timing
  sleep 5  # warmup/between steps

  # Snapshot 1
  kill -USR1 $AGENT_PID 2>/dev/null || break
  sleep 0.1
  S1_SERVER=$($CLI -h $REDIS_HOST -p $REDIS_PORT QUEUESTATE 2>/dev/null)
  echo "$S1_SERVER" > "$RESULTS/server_snap_${SNAP_IDX}_1.txt"

  sleep $INTERVAL

  # Snapshot 2
  kill -USR1 $AGENT_PID 2>/dev/null || break
  sleep 0.1
  S2_SERVER=$($CLI -h $REDIS_HOST -p $REDIS_PORT QUEUESTATE 2>/dev/null)
  echo "$S2_SERVER" > "$RESULTS/server_snap_${SNAP_IDX}_2.txt"

  # Client snapshots are in /tmp/lancet_qstate_N.txt
  # Copy them with index
  cp /tmp/lancet_qstate_$((SNAP_IDX*2)).txt "$RESULTS/client_snap_${SNAP_IDX}_1.txt" 2>/dev/null
  cp /tmp/lancet_qstate_$((SNAP_IDX*2+1)).txt "$RESULTS/client_snap_${SNAP_IDX}_2.txt" 2>/dev/null

  SNAP_IDX=$((SNAP_IDX + 1))
done

echo "Snapshot loop done. Took $SNAP_IDX snapshot pairs."
SCRIPTEOF

chmod +x ~/snapshot_loop.sh

STEP 8: VM2 — CREATE COMPUTE SCRIPT
============================================================

cat > ~/compute_latency.py << 'PYEOF'
#!/usr/bin/env python3
"""
Reads snapshot pairs from ~/results/ and computes latency.
Run after experiment completes.
"""
import os, glob

results_dir = os.path.expanduser("~/results")
interval = 2  # must match snapshot_loop.sh INTERVAL

print("snap_idx,L_total_us,L_unacked_us,L_unread_client_us,L_ackdelay_server_us,L_unread_server_us")

idx = 0
while True:
    c1_path = f"{results_dir}/client_snap_{idx}_1.txt"
    c2_path = f"{results_dir}/client_snap_{idx}_2.txt"
    s1_path = f"{results_dir}/server_snap_{idx}_1.txt"
    s2_path = f"{results_dir}/server_snap_{idx}_2.txt"

    if not all(os.path.exists(p) for p in [c1_path, c2_path, s1_path, s2_path]):
        break

    s1c = [int(x) for x in open(c1_path).read().split()]
    s2c = [int(x) for x in open(c2_path).read().split()]
    raw1 = open(s1_path).read().split()
    s1s = [int(x) for x in raw1 if x.lstrip('-').isdigit()][1:13]
    raw2 = open(s2_path).read().split()
    s2s = [int(x) for x in raw2 if x.lstrip('-').isdigit()][1:13]

    dt = interval * 1e9

    def Lat(p, n):
        Q = (n[1] - p[1]) / dt if dt > 0 else 0
        lam = (n[2] - p[2]) / (dt / 1e9) if dt > 0 else 0
        return Q / lam if lam > 0 else 0

    L_ua = Lat(s1c[0:4], s2c[0:4])
    L_ur_c = Lat(s1c[4:8], s2c[4:8])
    L_ad_s = Lat(s1s[8:12], s2s[8:12])
    L_ur_s = Lat(s1s[4:8], s2s[4:8])
    Lt = L_ua - L_ad_s + L_ur_c + L_ur_s

    print(f"{idx},{Lt*1e6:.2f},{L_ua*1e6:.2f},{L_ur_c*1e6:.2f},{L_ad_s*1e6:.2f},{L_ur_s*1e6:.2f}")
    idx += 1

print(f"\nProcessed {idx} snapshot pairs.")
PYEOF

chmod +x ~/compute_latency.py

STEP 9: VM2 — RUN THE EXPERIMENT
============================================================

# Start the lancet agent (stays up for entire experiment)
rm -f /tmp/lancet_qstate_*.txt
taskset -c 1 ~/patched-lancet/agents/assets/agent \
  -t 10.0.0.1:6379 \
  -p "redis_fixed:16_fixed:16384_1_1.0_rr" \
  -c TCP -T 1 -C 1 -r 1 &
AGENT_PID=$!
sleep 3

# Start snapshot loop in background
~/snapshot_loop.sh $AGENT_PID 2 &
SNAP_PID=$!

# Run coordinator — sweeps RPS from 1000 to 80000 in steps of 2500
# Coordinator stays connected to agent the whole time
~/patched-lancet/coordinator/coordinator \
  -symAgents 127.0.0.1 \
  -targetHost "10.0.0.1:6379" \
  -comProto TCP \
  -appProto "redis_fixed:16_fixed:16384_1_1.0_rr" \
  -loadThreads 1 \
  -loadConn 1 \
  -reqPerConn 1 \
  -loadPattern "step:1000:80000:2500"

# Coordinator finished — stop snapshot loop
kill $SNAP_PID 2>/dev/null
kill $AGENT_PID 2>/dev/null

echo "Experiment done."

============================================================
NOTES
============================================================

1. The snapshot_loop takes a pair every ~7 seconds (5s wait + 2s interval).
   The coordinator's step mode runs each RPS point for several seconds
   (until it converges). The snapshots will align approximately with
   the RPS steps — not perfectly, but close enough for a smooth curve.

2. For the 4 sub-experiments, repeat Steps 9-10 changing:
   - Workload: change "1.0" to "0.95" in appProto for mixed (95% SET, 5% GET)
   - Nagle: to enable Nagle, we need to remove TCP_NODELAY from the lancet
     agent's connection setup (in tp_tcp.c, comment out the setsockopt TCP_NODELAY
     line in throughput_open_connections). Rebuild agents after change.

3. If the coordinator doesn't build (Go issues), fall back to redis_bench.c:
   gcc -O2 -o ~/redis_bench ~/patched-redis/redis_bench.c -static
   Then use ~/patched-redis/run_experiment.sh instead (no lancet needed).

============================================================
FALLBACK: If snapshot timing doesn't align with RPS steps
============================================================

Alternative: run coordinator in fixedTime mode per RPS point.
This means one coordinator invocation per RPS, with snapshots in between.
Downside: agent may reset between runs (warmup variance).

To do this, replace Step 9 with a loop:
  for RPS in 1000 2500 5000 ... 80000; do
    ~/patched-lancet/coordinator/coordinator \
      -symAgents 127.0.0.1 \
      -targetHost "10.0.0.1:6379" \
      -comProto TCP \
      -appProto "redis_fixed:16_fixed:16384_1_1.0_rr" \
      -loadThreads 1 -loadConn 1 -reqPerConn 1 \
      -loadPattern "fixedTime:$RPS:12" &
    COORD_PID=$!
    sleep 5  # warmup
    kill -USR1 $AGENT_PID  # snapshot 1
    S1=$($CLI -h 10.0.0.1 QUEUESTATE)
    sleep 2  # interval
    kill -USR1 $AGENT_PID  # snapshot 2
    S2=$($CLI -h 10.0.0.1 QUEUESTATE)
    wait $COORD_PID
  done
